# Вопросы заказчику перед стартом работы

**Цель встречи:** договориться, *что* делаем в первой версии и *для кого*, простым языком — без технических деталей.

**Как пользоваться:** можно идти по порядку. На вопросы с вариантами достаточно выбрать один ответ. Если ответа нет — ставим «решим позже» и идём дальше.

---

## 1. Зачем нам это приложение

1. **Какую главную проблему** должно решить приложение одной фразой?  
   *(Например: «не видно, как несколько направлений работ складываются в одну большую цель» / «планы есть в голове, а на картинке их нет».)*
Ответ: Запускать с портала на рабочем столе. Это будет сетевой график и канбан. Чтобы каждый участник мог увидеть куда и как мы двигаемся.

2. **Что важнее показать на первом демо?**  
   - А) Картинку с путями и сроками (схема)
   - Б) Доску с карточками работ (канбан)  
   - В) И то, и другое сразу (дольше по срокам)
Ответ: Вариант В.

3. **К какой дате** нужно первое живое демо, чтобы понять: «нравится / не нравится»? 
Ответ: Без даты, просто задача.

4. **Что будет считаться успехом демо?**  
   *(Например: «руководитель за 10 минут понял план» / «команда смогла вести реальный небольшой проект».)*
Ответ: Основатель смог собрать схему достижения цели и назначил ответственных на каждую задачу. Ответственный за задачу сделал оценку времени на ее исполнение и внес это на схему. Таким образом схема приобретет живой вид.
---

## 2. Кто будет пользоваться

5. **Кто основные пользователи** в первой версии?  
   - Руководитель / менеджер проекта  
   - Тимлид / старший специалист  
   - Вся команда  
   - Другое: ________
Ответ: Все.

6. **Сколько человек** примерно будут работать с одной большой целью одновременно?  
   *(1–3 / 5–15 / 20+)*
Ответ: Без ограничений.

7. **Нужно ли сразу несколько компаний** (разные организации со своими данными) или на первое время хватит **одной тестовой**?
Ответ: Для теста достаточно будет одной компании.

8. **Кто что может делать?** Нужны ли разные уровни доступа уже в первой версии?  
   - Все могут всё  
   - Есть «только смотреть» и «можно менять»  
   - Есть владелец цели, редакторы и наблюдатели (как в ТЗ)
Ответ: Уровни пока не нужны.

---

## 3. Как выглядит работа со схемой (пути к цели)

9. **Что означает цифра/подпись на стрелке** между задачами?  
   - Сколько времени займёт **предыдущая** задача  
   - Сколько ждать **между** окончанием одной и началом следующей  
   - Затрудняюсь — покажите оба варианта на демо
Ответ: Сколько времени займёт предыдущая задача.

10. **Можно ли начинать следующую задачу**, если предыдущая ещё не закончена?  
    - Да, freely (просто предупредить)  
    - Нет, система не даёт  
    - Пока не важно
Ответ: Да. Каждая задача живет своей жизнью.

11. **Нужны ли «вехи»** (контрольные точки без канбана) уже в первой версии, или достаточно обычных задач + финальной цели?
Ответ: Не поняли вопроса.

12. **Пути на схеме** — это скорее:  
    - Именованные дорожки («Маркетинг», «Разработка»)  
    - Или просто линии задач, которые сами собой читаются как пути
Ответ: Просто линии задач, которые сами собой читаются как пути.

13. **Откуда брать планы в первой версии?**  
    - Только руками рисовать в приложении  
    - Нужен импорт из Excel / другого трекера сразу
Ответ: Нужно и то и другое. Импорт нужен пока только из Excel.
---

## 4. Доска внутри задачи (канбан)

*Напоминание: колонки зафиксированы — «Задача → В работе → Тестирование → Готово».*

14. **Этих четырёх колонок достаточно** для ваших процессов или очень хочется другие названия/число колонок?
Ответ: Да.

15. **Что обязательно должно быть на карточке уже в первом демо?** Отметьте нужное:  
    - [x] Название и описание  
    - [x] Ответственные  
    - [x] Срок  
    - [ ] Метки (теги)  
    - [x] Приоритет  
    - [x] Чек-лист  
    - [x] Комментарии  
    - [x] Учёт затраченного времени  
    - [x] Вложения файлов  
    - [x] История «кто что менял»

16. **Нужно ли ограничивать**, сколько карточек может лежать «В работе» одновременно (чтобы не расползалась нагрузка)?
Ответ: Ограничивать не нужно.

17. **Кого можно назначать ответственным** в первой версии?  
    - Список людей из вашего основного портала  
    - Просто имена/учётки внутри нашего тестового приложения  
    - Пока не важно
Ответ: Пока не важно.
---

## 5. Связь с основным порталом (потом)

*Сейчас делаем отдельное приложение. Эти вопросы — чтобы понимать «куда плывём».*

18. **Если идея понравится**, куда вы хотите встроить это в портале?  
    *(Отдельный пункт меню / внутри проекта / ещё не решили.)*
Ответ: Отдельный пункт меню.

19. **Кому в компании** вообще можно будет открывать этот раздел в портале?  
    *(Все сотрудники / только админы / конкретные роли — перечислите как называете их у себя.)*
Ответ: Все сотрудники.

20. **Должны ли задачи из Visual Paths когда-нибудь совпадать** с уже существующими задачами портала, или это отдельный мир?
Ответ: Отдельный мир.

21. Есть ли у вас **готовый фирменный стиль** (цвета, шрифты, макеты), под который нужно подстроиться, или на демо можно свой аккуратный вид?
Ответ: Можно свой аккуратный вид.
---

## 6. Практические договорённости

22. **Где будет жить тестовая версия** для демо?  
    - На вашем сервере  
    - Мы поднимаем сами и даём ссылку  
    - Пока только на компьютере разработчика
Ответ: Пока только на компьютере разработчика.

23. **На каком языке** интерфейс в первой версии: только русский или сразу русский + английский?
Ответ: Только русский.

24. **Кто с вашей стороны** отвечает на вопросы по ходу разработки и принимает демо? (имя / роль)
Ответ: Я ответственный за все.

25. **Есть ли уже реальный пример** большой цели, на котором можно проверить приложение?  
    *(Кратко опишите или пришлите список этапов — это сильно ускорит демо.)*
Ответ: Нет, например можно взять цель "Постройка дома для продажи" и разбить ее на задачи.
---

## Краткая шпаргалка для ведущего встречи

| Если заказчик сомневается | Можно предложить по умолчанию |
|---------------------------|-------------------------------|
| Схема или канбан первым | Сначала схема, канбан — простой |
| Несколько компаний | Одна тестовая |
| Жёсткий запрет «идти вперёд» | Только предупреждение |
| Импорт из Excel/Jira | Не в первой версии |
| Файлы на карточках | Не в первой версии |
| Язык | Только русский |
| Вехи отдельно | Не в первой версии |
