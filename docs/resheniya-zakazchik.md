## Зафиксировано

| Тема | Решение |
|------|---------|
| Суть продукта | Сетевой график (схема путей) + канбан; видно, куда движется команда |
| Первое демо | **И схема, и канбан** сразу |
| Срок демо | Без жёсткой даты |
| Успех демо | Основатель собрал схему → назначил ответственных → ответственные оценили время и внесли на схему → схема «ожила» |
| Пользователи | Вся команда |
| Число людей на цель | Без лимита (технически заложить запас) |
| Компании в тесте | Одна тестовая |
| Роли/доступы в v1 | Не нужны (все могут всё) |
| Подпись на стрелке | Время выполнения **предыдущей** задачи |
| Старт следующей до Done предыдущей | **Да**, задачи независимы |
| Вехи | **Отдельного типа нет** — всё через обычную задачу (+ цель) |
| Пути | Без именованных дорожек — линии задач сами читаются как пути |
| Ввод планов (демо) | **Только руками**. Импорт Excel — **позже** |
| Колонки канбана | 4 шт., как в ТЗ — ок |
| На карточке must (демо) | название, описание, ответственные, срок, приоритет, чек-лист, комментарии, учёт времени, история |
| Вне scope демо | **Файлы**, **импорт Excel**, метки, WIP |
| Assignees | Пока свои учётки тестового приложения |
| «С портала на рабочий стол» | **Будущее** (виджет/portal), не первое демо |
| В portal потом | Отдельный пункт меню, все сотрудники |
| Связь с задачами portal | Отдельный мир |
| Дизайн | Свой аккуратный вид |
| Хостинг демо | Компьютер разработчика |
| Язык | Только русский |
| Приёмка | Заказчик сам |
| Пример для демо | «Постройка дома для продажи» |

---

## Scope первого демо (кратко)

**Делаем:** схема + канбан (без файлов) + назначения и оценки времени на схеме.  
**Не делаем сейчас:** Excel, вложения файлов, отдельный тип «веха», интеграция с portal.

---

## Риски (актуально)

1. Объём всё ещё заметный (схема + насыщенный канбан), но без Excel/файлов — **приемлемее**.  
2. Успех демо = назначения + оценки на схеме — must с первых фаз.  
3. Много пользователей «без лимита» при одной тестовой компании — лимит в UI не ставим, нагрузку не обещаем на сотни сразу.

---

## Порядок работ

1. Схема: узлы, стрелки (длительность предыдущей), назначения, оценки.  
2. Канбан узла: must-поля без файлов и меток.  
3. История карточки.  
4. Демо на «Постройка дома для продажи».  
5. Позже: Excel, файлы, встройка в portal.
