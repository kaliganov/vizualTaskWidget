## Фаза 1 — каркас (сейчас)

- `server/` — Nest.js, TypeORM, PostgreSQL, JWT
- `web/` — React + Vite + TypeScript
- `docker-compose.yml` — Postgres
- Auth: email + пароль (без OTP)
- `GET /api/v1/users` — список для assignees
- Префикс API: `/api/v1/visual-paths`

## Фаза 2 — схема (ядро продукта)

- Узлы `task` + якорь цели; без именованных дорожек
- Ребро: `durationValue` + `durationUnit` = оценка предшественника
- Запрет циклов (DAG)
- Drag по X ≈ дата (snap к дню)
- Autosave графа (`version` + 409)
- Двойной клик → заглушка канбана, затем Phase 3

## Фаза 3 — канбан

Колонки: Задача | В работе | Тестирование | Готово.  
Must на карточке — как в решениях заказчика. Без меток, WIP, файлов.

## Фаза 4–5

История, прогресс на схеме, сид дома, приёмка заказчиком.
