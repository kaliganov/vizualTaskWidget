# Остановка демо

Команды из корня репозитория. Данные базы сохраняются.

1. В терминале веба нажмите Ctrl+C и дождитесь выхода `npm run dev:web`.
2. В терминале API нажмите Ctrl+C и дождитесь выхода `npm run dev:server`.
3. Остановите контейнер, не удаляя том:

```bash
docker compose stop
```

Контейнер `visualtask-db-1` должен быть в состоянии `Exited`. Том `visualtask_pgdata` остаётся.

Не используйте `docker compose down -v` и не удаляйте том `pgdata`: это сотрёт цели и схемы.

Docker Desktop после этого можно оставить запущенным или закрыть. Закрытие программы данные не удаляет.
