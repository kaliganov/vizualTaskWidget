# Старт демо

Команды из корня репозитория. Том Postgres не удалять.

1. Запустите Docker Desktop и дождитесь, пока демон поднимется.
2. Поднимите базу:

```bash
npm run db:up
```

Контейнер `visualtask-db-1` должен быть в состоянии `Up`.

3. В двух отдельных терминалах:

```bash
npm run dev:server
```

```bash
npm run dev:web
```

4. Проверьте, что оба отвечают:

- интерфейс: http://127.0.0.1:5173/
- API: http://127.0.0.1:3001/health

Адрес `http://127.0.0.1:3001/api/v1/health` не используется: проверка живости лежит на `/health`.
